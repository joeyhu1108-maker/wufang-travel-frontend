# 无方旅行原生小程序｜当前事实

更新：2026-10-05。完整上线工作包见 `../launch/README.md`。

现有线上飞书链接是 H5 交互预览，不是已发布的微信小程序。

原生目录 `miniprogram/` 有首页、路线列表、路线详情、预约咨询、我的、隐私说明共 6 页。探索、社区、团期与交易等完整体验目前仍在 H5 中，尚未完成原生迁移；不要以 H5 截图代替原生验收。

## 本轮已准备

- 开发／体验／正式版本隔离，只有开发版能使用参考路线；未配置云环境时体验和正式版本失败关闭。
- 云函数可信身份登录、已审核路线读取、真实咨询保存的代码基础。
- 咨询校验、隐私版本确认、失败重试、幂等与防重复提交；不会假登录、假保存或假收款。
- 定版 Logo 的原样格式转换及本地封面，避免依赖外部随机图片。
- 本地自动检查、真实验收清单、甲方资料模板、云部署步骤及发布阻断检查。

这些是本地代码准备，不等于云函数部署、微信编译、真机验证或审核通过。

## 导入与联调

1. 在微信开发者工具导入 `miniprogram/`；使用真实 AppID 前先由甲方授权开发者。
2. `project.config.json` 已配置真实 AppID；这不证明后台权限或上传授权。云环境仍未配置，环境 ID 在 `config.js` 配置，不在 `app.js` 写死。
3. 云函数位于单独的 `cloudfunctions/wufangApi/`。不要误把整个仓库当作小程序主包上传。
4. 云配置和安全审计要求见 `../launch/CLOUD-DEPLOYMENT.md`；SDK 依赖风险未关闭前不得部署正式服务。
5. `config.js` 改为 `mode: 'cloud'`，填写环境 ID、已确认的隐私正文／版本及客服电话。商户密钥、支付证书、腾讯云 SecretKey 不得放入小程序。

## 检查命令

在仓库根目录执行：

```sh
npm run check:miniprogram
npm test
npm run check:release
```

`check:miniprogram` 仅做静态和文件完整性检查；`check:release` 还核对真实账号、原生功能、验收证据与云依赖安全。当前严格检查应当失败，这是保护门槛，不应关闭来强行发布。
