# 与无方同行 · 实拍素材接入

2026-09-16，本轮仅更新本地移动端设计原型，未公开部署，也未改变真实交易能力。

## 展示位置

- 首页：路线推荐之后增加一组「旅途里的我们」，保留简约首屏与原品牌标识。
- 路线详情「这一路」：增加同行照片和影像入口；阿里展示湖畔合坐，冈仁波齐展示步行同行。照片作为品牌旅途记录，不代表未来团期人员或服务承诺。
- 「与无方同行」二级页：4 张照片、2 条实拍短片；首页、路线详情和「我的」均可进入，不新增底部 Tab。
- 照片支持放大；短片点击后才创建播放器，默认静音、原生控件、行内播放。关闭弹层清除视频源，切入后台暂停。
- 本轮没有替换既有开屏视频，也没有生成或剪辑新的影片。

## 对外发布前需确认

素材包未明确区分领队、工作人员与客人，因此只使用「同行者／旅人」描述，不编造身份或姓名。请客户确认出镜者展示许可、素材使用权以及视频原声音轨的使用范围。已发现有其他来源水印的候选短片未使用；默认静音不等于原音乐已获得授权。

蓝调视频保留约 15 MB 原文件；它仅在点击播放时请求，不随首页下载。正式上线前按实际网络环境做压缩与加载性能验收。

## 验证

运行 `npm run verify` 检查语法、单元测试、构建与素材完整性；浏览器另外检查手机宽度、入口返回、照片比例和视频启停。

本轮通过 59 项自动测试及 25 个素材完整性检查。浏览器实际打开 4 张照片（原尺寸正常解码），两段视频分别播放到 10.53 秒、13.03 秒结尾（readyState 4）；关闭后 paused 为 true、src 已移除。320px 下影像页无横向溢出，播放按钮与时长条不重叠。未在实体手机 / 微信内测量加载速度。
