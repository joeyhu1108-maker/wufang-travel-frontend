- 照片仅接受 JPG / PNG / WebP，单张不超过 10 MB；本地缩至长边不超过 1440 px，并重编码为 JPEG，不保留原文件 EXIF。
- 自动存草稿、手动存草稿、刷新恢复、提交待审核、撤回再编辑、回收站与恢复。
- 喜欢、收藏、留言和反馈；留言同样保持待审核状态。
- 首批公开内容明确标为“无方影像”，使用既有授权项目素材，不伪装成团友评价，不编造用户或热度。

入口：`/mobile-design/index.html?v=community-1#community`。

## 审核与真实服务边界

当前是可操作的前端预览。图文与互动保存在当前域名下的 IndexedDB，账号使用项目现有演示登录；没有发送给团队，没有接入真实审核、云存储、内容安全接口或小红书跳转。本轮未重新部署线上预览。

```
草稿 → 提交审核 → 待审核（不出现在公开列表）
                    ↓ 撤回
                   草稿
草稿/待审核 → 回收站 → 恢复为草稿
```

正式产品：服务端审核通过后才能进入公开列表。预览不提供面向团友的“自助通过审核”，也不将等待数秒当成审核成功。

本地体验账号不是安全身份；同一浏览器的本地内容不是跨账号隔离的数据空间。请使用测试内容，勿填写证件、联系方式等隐私。清理网站数据、换域名或换设备不会自动迁移草稿。生产多设备同步不能直接复用整库读写的本地存储方式。

## 正式接入时必须完成

1. **身份与权限**：使用真实登录身份及服务端作者 ID；只有作者能查看草稿、撤回或编辑。游客只能读取审核通过的内容。不可依赖昵称或前端按钮权限。
2. **图片存储**：受控上传、尺寸/类型/配额验证、对象存储和访问权限；待审核图片不得通过公共地址绕过审核。小程序改用平台选图与上传能力，不使用 DOM 文件输入。
3. **审核工作流**：团队受权人员可通过、退回并填写原因、下架；文本及图片安全检测、审核日志、举报处理。发帖和留言分开审核，失败不自动放行。
4. **服务端操作**：公开列表、我的投稿、保存草稿、提交审核、撤回、软删除/恢复、喜欢/收藏、留言、反馈分别提供接口；并发版本检查、提交幂等、防重复和限流。正式数据状态由服务端决定。
5. **发布结果**：只有接口确认成功才展示投稿成功；离线/超时保留草稿并提供重试。审核中的修改必须撤回或重新审核，不能覆盖已通过版本。
6. **上线材料**：内容与照片授权、社区规范/隐私说明、审核负责人及处理时效、测试账号和上线验收。密钥仅通过安全环境配置，不写入前端或仓库。

本轮未增加大型运营工作台。审核管理界面与服务端接入另行实现，不能把本地 IndexedDB 当作上线后台。
