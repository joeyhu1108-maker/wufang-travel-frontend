# 探索移动端体验调整

更新日期：2026-09-21。此轮为本地前端设计与交互调整，未部署、未接通跨小程序跳转。

## 页面与动线

- `#explore`：探索手册。第一张卡片为路线漫游，第二张为更大幅的风雪脉动；保留现有品牌 Logo 与主导航。
- `#explore-roam`：原生滚动叙事。两条路线各有六站图文故事，滚动同步更新顶部站点与路线示意；保留轻点跳站和随时查看行程的入口。结尾连接完整行程，海拔轴按需展开；从详情返回时保留阅读位置。
- `#explore-weather`：独立三维雪山体验。默认以地形为主体，选择雪山、图层、时间和视角均可直接操作。详细天气通过底部弹层查看。
- 返回手册会卸载三维 iframe；进入手册不预加载三维地图。

## 移动适配

- 漫游不接管滚轮或触摸，不强制吸附和锁屏。顶部导航与小地图固定，正文自然滚动；短屏收紧小地图，低矮横屏只保留跳站栏。切换页面移除滚动监听，减少动态效果偏好下跳站直接定位。
- 常规竖屏：上方选择雪山，中间地形，底部固定操作区。
- 短屏：收紧标题与说明，视角按钮改为两列，保留放大、缩小、环绕与复位功能。
- 宽横屏：画面在左，操作区在右，避免上下挤压地形。
- 核心操作点击区至少 44px；保留减少动态效果偏好与键盘焦点样式。
- 时间轴支持手动选择及逐小时播放；到末小时停止，再次播放从首小时开始；选山、手动拖动、打开详细数据或切入后台时暂停。

## 数据边界

沿用 Open-Meteo 预报、Mapterhorn 地形与 Esri 影像。天气是模型预报，风线、雪粒与云雾是视觉表达，不是现场实况，也不作为出行安全判断。详细数据保留来源与边界说明；数据加载失败时不生成假天气。

地图与天气仍依赖外部网络；此轮未验证中国不同地区、微信 WebView 或真实手机的网络与性能。

- `npm run verify`：语法、88 项测试、生产构建及可迁移静态资源检查通过。新增覆盖六站内容与路线数据一致性、阅读线正反滚动/快速跨站，以及监听清理与恢复约束。
- 浏览器 CSS 视口：390×844、320×约568、844×390。检查手册、独立三维页面、横屏布局与水平溢出。

- 漫游：自然滚动与逆向阅读更新当前站；轻点冈仁波齐准确定位到固定栏下方；从 10 天路线进入详情再实际点击返回，滚动位置从 2089.375px 恢复到同一位置。13 天路线关联正确详情，海拔轴末端为 D13 / 拉萨 / 3600m。

- 测试时地形和天气成功加载，检查时浏览器未报错。并不等同于所有终端或网络已通过验收。
