# 藏地山居 · 视觉更新 V2.3

2026-09-08。目标：让西藏成为界面的整体气质，并改善阅读与预订界面的完成度；保留可迁移 HTML／CSS／JavaScript 架构。

## 视觉决定

- 暖白与浅砂作为纸面和墙面感，赭红用于行动、选中状态及少量边饰。暗色用于正文，不采用黑金奢华模板。
- 首页由全屏暗照片改为纸面叙事与框景的双页构图；手机端重排为标题、行动、风景，保留照片主体。
- 以原创细织纹色带和「藏地行记」中文印记作线索，不使用伪藏文，也不借用宗教图案来装饰支付界面。
- 路线卡片、现场影像采用照片与纸面标题分离；路线信息、日期选择、金额和按钮有清晰层级。
- 预订的日期、出行人、核对、支付、结果保持原流程；更换面板、状态与票据样式，固定底部合计与下一步。
- 旅人护照 PNG 导出读取主题配色，保留原 Logo 与 1080 × 1560 画幅。

织物材料的参考来自 [大都会博物馆的西藏羊毛围裙条目](https://www.metmuseum.org/art/collection/search/126748)。界面的色带是原创抽象处理，不是传统纹样的考据复刻；没有下载或使用该馆藏图像。风景照片与 Logo 仅沿用本项目已提供素材，原文件未改动。

## 修改范围

- `index.html`：首屏构图、品牌文字、快捷入口文案、路线区标题及主题入口。
- `src/wufang/styles-tibet.css`：主视觉、控件、预订弹窗、响应式及减少动画设置。
- `src/wufang/app.js`：仅调整护照导出的主题配色。
- 未改动路线／日期／价格数据与订单状态逻辑；未新增第三方字体、CDN 或平台 SDK。

## 复核

基础验证：`npm run verify`。

`scripts/qa-visual.mjs` 检查五种宽度并生成各区截图；`scripts/qa-booking.mjs` 回归预订全流程。两者可通过 `PLAYWRIGHT_MODULE` 和 `CHROME_BIN` 指向本地安装；浏览器截图与详细范围见 `VERIFICATION.md`。

本版仅本地预览，支付依然不扣款，未发布到原公网地址。真实手机、微信内置浏览器和上线链路需另行验收。
