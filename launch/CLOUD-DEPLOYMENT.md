# 云开发与存储｜购买及部署路径

更新：2026-10-05。当前未创建收费资源、未上传真实客户资料、未部署正式云函数。

## 购买入口

优先使用客户主体下的小程序云开发，不把客户数据永久放在交付方私人账号中。

1. [微信公众平台](https://mp.weixin.qq.com/)：甲方管理员确认 AppID、主体、成员权限、类目及备案。
2. [腾讯云 CloudBase 控制台](https://console.cloud.tencent.com/tcb)：使用甲方账户／已授权账号，确认微信小程序关联与账单归属，选择环境及资源套餐。
3. [腾讯云官方购买说明](https://cloud.tencent.com/document/product/876/56375)：以当日控制台可用套餐、地区、配额与计费为准。本次未给出固定单价，也不自动购买。
4. 微信开发者工具的云开发入口用于关联已授权环境和联调；菜单与可开通产品以实际账号为准。

存储、数据库、云函数、带宽／下载、日志可能分别消耗配额。素材小不代表视频播放费用小。不要只买“存储容量”就当整个后台已经具备。

内部资源预算不代表平台包年承诺或自动开通授权。先估算素材大小、访问量及视频出网，确认支付方、预算、超额审批与停用策略，再购买；运营维护费与平台账单分开。具体商业报价不在公开交接范围。

## 账号与权限

- 管理员、商户管理员与最终发布权归甲方。开发者使用被邀请的个人身份，不共享密码或二维码会话。
- 云环境尽量区分开发与正式；`trial` 可以指向开发环境，但不能混用真实订单／旅客数据。三个配置项都需显式填写。
- 云端最小授权：只提供需要的环境和功能；发布、账单及敏感凭证限制到负责人员。
- 开启可用的预算／用量告警，记录告警接收人。定期查看数据库、函数、存储、出网和日志开销，首月复核；不要口头假设平台一定提供自动封顶。

## 当前可以联调的代码

`cloudfunctions/wufangApi/` 仅支持 `login`、`listRoutes`、`getRoute`、`createInquiry`。

没有实现下单、锁座、支付、退款、管理后台或社区审核。云控制台中的手工数据操作只用于技术联调，不是可交付的运营后台。

### 部署前

1. 处理 `SECURITY-DEPENDENCIES.md` 中依赖风险。正式环境当前被阻断；不要先部署再补审计。
2. 在函数目录执行 `npm ci --ignore-scripts` 安装锁定依赖；确认云运行时支持所用 Node API，并在该运行时进行构建与实测。不要自行推断云端 Node 版本。
3. 在开发环境创建 `routes`、`inquiries`、`inquiry_limits` 集合。逐个应用 `database-rules.json`：客户端读写均拒绝。
4. 配置函数环境变量 `WUFANG_APP_ID`、`WUFANG_PRIVACY_VERSION`，与小程序的真实 AppID 及已确认隐私版本一致。这些值不是商户密钥。
5. 用云控制台／开发者工具选择目录 `cloudfunctions/wufangApi/`，函数名 `wufangApi`。这是单独部署，不放进小程序主包。当前项目没有声明云函数根目录，勿误把仓库根作为原生目录上传。
6. 不开启公共 HTTP 触发器；保持微信可信上下文调用。`APPID` 或 `OPENID` 缺失／不匹配会拒绝服务。
7. `routes-template.json` 是未发布模板。补最终价格（本接口展示单位元）、授权 HTTPS 封面和描述，经运营批准后才将 `published` 与 `approved` 设为 true。不可把演示团期当可售数据。
8. 函数日志不输出姓名、手机号、OPENID、表单原文或凭证；联调只用虚构数据。

[腾讯云安全规则文档](https://cloud.tencent.com/document/product/876/41802) 明确客户端规则与服务端管理调用的权限不同：拒绝客户端读写不等于云函数已安全，所以函数仍需逐动作核验身份、业务角色和资源归属。

### 原生配置

`miniprogram/project.config.json`：已配置真实 AppID，仍需甲方核对归属并授予开发权限；配置值不是平台授权证明。

`miniprogram/config.js`：

```js
module.exports = {
  mode: 'cloud',
  environments: {
    develop: '客户的开发环境ID',
    trial: '客户的体验环境ID',
    release: '客户的正式环境ID',
  },
  functionName: 'wufangApi',
  privacyVersion: '客户确认的政策版本',
  privacyText: '客户确认的完整隐私正文',
  supportPhone: '真实客服电话',
};
```

示例值不可直接复制作为正式配置。只有开发版的 `mode: 'preview'` 可读参考路线；体验及正式版本不会回退到假数据。初始化 SDK 成功不等于后端正常，必须实测每个接口。

### 存储与数据保护

- 开屏、封面及公开视频使用已授权素材，图片压缩、视频转码及 CDN 策略按实际能力验证；大视频不塞进主包。
- 私有投稿与公开素材分路径／存储策略；未审核照片必须需要授权访问，不能靠“不显示链接”来保护。
- 服务端签发上传权限并校验用户、文件类型、数量与大小；内容检查后交团队审核。当前代码尚无上传接口。
- 咨询 `inquiries` 含个人信息，仅受控客服／运营访问；上线前确定保存期限与用户删除路径。
- `inquiry_limits` 是去重／限流记录，需要清理策略。正式环境增加定时清理与失败告警，期限由数据管理方案确认。
- 对数据和存储进行备份，记录恢复点及权限。必须完成隔离环境恢复演练，不能只截图“备份已开启”。

## 联调完成标准

支付阶段另外接通商户服务、回调域名、验签、主动查单与退款。首次真实收费之前需甲方授权，不能将咨询回执当订单号。
