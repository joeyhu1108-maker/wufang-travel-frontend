## 参考与取舍

参考用户本轮提供的「选团助手」截图，不将单张截图当作已验证的完整产品动线。

- 截图可见：紧凑顶栏、五项筛选、横排快捷标签、路线大图、标题和类型、横排日期 / 价格 / 余位卡片、底部导航。
- 本轮借鉴：先筛选，再横滑比较团期，点具体团期直接确认人数；点封面或路线名查看完整详情。
- 自行补全：筛选用底部弹层承载，选项先暂存，点击「查看结果」才应用；关闭或 Escape 取消本次修改。
- 业务边界：沿用两条无方路线及既有演示价格、日期、余位，不新增截图中的地区、产品和库存。不将余位推断为已成团，第四项暂用「余位」筛选；真实成团状态需甲方补充。
- 保留：最终完整 Logo、发现首页、探索、团队素材、详情、账号和支付沙盒。底部仍为「发现 / 路线 / 探索 / 我的行程」。

## 组件与接入

- `public/mobile-design/group-picker.mjs`：筛选定义、结果计算、团期卡片、筛选弹层、紧凑团期确认页。
- `public/mobile-design/group-picker.css`：仅针对新增选团界面；主界面仍使用已有设计系统和品牌资产。
- `public/mobile-design/ui.js`：交互状态接入、筛选提交 / 取消、返回时恢复列表纵向位置与团期横向位置。
- `test/group-picker.test.mjs`：10 项新增自动测试。

业务数据仍取自 `data.mjs`。用户选择具体团期时保留路线、日期与人数；费用继续由既有订单适配器按路线单价计算。页面不新增真实账号、订单或付款接口。
