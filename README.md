## 以下为初始独立前端 V2.3 的说明

这是一份可迁移的 H5 源码，基于已发布的无方 V2（源提交 `6dbbbdc9e0cb987f9d53e1e2f471f0068d7703d1`）。使用标准 HTML、CSS、JavaScript ES Modules；Vite 仅负责开发与打包。页面运行不需要飞书 SDK、飞书登录、专用服务器或环境变量。图片与 Logo 随工程交付。

## 开发

安装 Node.js 24，然后在当前目录执行：

```sh
npm ci
npm run dev
```

浏览器打开终端显示的本地地址。`npm ci` 首次需要联网下载开发依赖，最终网页不需要访问 npm 或任何第三方资源域名。

## 构建与部署

```sh
npm run verify
npm run preview
```

把 `dist/` 内的所有文件上传到普通静态网站空间即可。服务器无需 Node.js，也无需安装依赖。可部署在域名根目录，或如 `/travel/` 这样的子目录；子目录地址必须以 `/` 结尾。页面通过锚点及浏览器历史导航，不需要 SPA 路由重写。

不要通过双击 `index.html` 打开源码：浏览器的 ES Modules 需要 HTTP 服务。`npm run preview` 用于本地验收，不是正式生产服务器。详细交接见 [部署与维护](docs/HANDOFF.md)。

## 当前功能边界

V2.3「藏地山居」重做首页、路线卡片、行程、护照及预订支付界面的视觉：暖白纸面、赭红、原创细织纹色带、雪山画幅与中文衬线排版。定版 Logo 与原有 15 个媒体文件保持不变；旅人护照导出随主题配色同步。详见 [视觉说明与验收](docs/TIBET-UI.md)。旧 `styles-v2.css` 保留作对照，不再加载。

已包含路线切换、交互地图、逐日行程、问卷、旅人护照 PNG 下载、画廊和咨询清单生成/复制/下载。问卷进度只保存在当前浏览器；咨询清单不会上传到服务器。

V2.2 新增完整预订演示：选路线 → 固定团期／自选日期 → 同行人数 → 出行信息 → 确认订单 → 微信／支付宝模拟收银台 → 成功、失败或取消 → 我的订单。可体验失败重试、待支付订单恢复及取消，刷新后仍可查看最近 30 笔演示订单。联系人、手机号、出行人称呼和备注只暂存在当前页面内存中，刷新即清除，不进入本地订单记录。

日期和余位为固定示例规则，演示价格沿用现有参考价，不锁位、不上传、不扣款、不连接微信或支付宝。没有真实订单、支付接口、客服后台、合同、退款或团期库存。请勿填写真实个人信息。

具体演示方法见 [预订流程与接口边界](docs/BOOKING-DEMO.md)。

业务数据与浏览器交互已分别放在 `model.mjs` 和 `app.js`。未来换 Vue/React 可以复用数据与纯函数，但需要接入新的界面组件。微信原生小程序需要适配页面组件、导航、存储及图片保存 API；这份 H5 不声称可以一键编译成原生小程序。

素材沿用本项目已使用的品牌资源，来源清单用于追溯，不额外授予第三方使用权。团期、客服联系方式、最终费用与退改规则仍待品牌方确认。
